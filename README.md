# Madhav Ecommerce Sales Dashboard 📊

An interactive Power BI dashboard designed to analyze and visualize e-commerce sales performance and generate meaningful business insights.

## 📌 Project Overview

The Madhav Ecommerce Sales Dashboard provides a comprehensive view of e-commerce performance across different states, customers, product categories, payment methods, and time periods.

The dashboard helps identify sales trends, profit drivers, customer contribution, and purchasing patterns through interactive visualizations and filters.

## 🎯 Objectives

- Analyze overall sales and profit performance
- Track key KPIs such as Amount, Profit, Quantity, and AOV
- Identify top-performing customers
- Analyze sales across different states
- Understand customer payment preferences
- Compare performance across product categories and sub-categories
- Analyze monthly profit trends
- Provide an interactive interface for business analysis

## 📊 Dashboard Features

### Key Performance Indicators
- **Total Amount**
- **Total Profit**
- **Total Quantity**
- **Average Order Value (AOV)**

### Visual Analysis
- Amount by State
- Quantity by Payment Mode
- Profit by Month
- Amount by Customer
- Quantity by Category
- Profit by Sub-Category

### Interactive Filters
- Quarter selection
- State selection

These filters allow users to explore the data dynamically and analyze specific segments.

## 💡 Key Insights

The dashboard enables analysis of:

- Which states contribute the most to sales
- Which customers generate the highest sales
- The most popular payment methods
- Product categories contributing the highest quantity
- Monthly profit fluctuations
- Sub-categories generating the highest profit
